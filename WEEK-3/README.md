# Week 3 - ASP.NET Core Web API & Kafka Integration

This repository contains the Week 3 hands-on assignments completed as part of the Cognizant Deep Skilling Program. The assignments focus on developing RESTful Web APIs using ASP.NET Core, implementing authentication with JWT, Swagger integration, CRUD operations, custom filters, and Kafka messaging.
